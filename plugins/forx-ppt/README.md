# ForX PPT 创作台

这是一个独立插件包：桌面创作工作区 + 插件 API + `hermes ppt` 命令 + 对话操作 skill。插件没有修改代理、网关或桌面核心代码，也没有新增常驻模型工具。

## 已实现

- 主题 / 大纲生成可持续编辑的文稿，提供 5 种原生版式、3 套主题及 16:9 / 4:3 页面。
- 文稿内稳定的页面编号 `S001`、元素编号 `E0003` 和语义名称；重排保留身份，复制分配新身份。
- 插件内 SVG 结构预览、缩略图、编号辅助层、点击选中、元素查找和修改前对比。
- 按编号修改文字、位置、尺寸、图片、表格、柱状 / 折线 / 饼图及组合对象；支持多对象操作组。
- 母版公共文字、图片及形状联动；标题 / 正文属性、版式区域和局部覆盖可分别修改与恢复继承。
- 全篇主题、颜色、字体与预设形状风格更新；默认保留局部样式。
- 事务式保存、版本检查、重复请求识别、取消未提交的模型指令、撤销 / 重做、历史恢复及实际影响范围记录。
- 原生 PPTX 导出，包含可编辑图表工作簿；导出名称包含元素编号；项目导出和自身 PPTX 元数据恢复。
- 数据保存于当前配置作用域的 `plugin-data/forx-ppt/projects.db`，支持一个后端服务多个配置。

## 安装与启用

在 ForX 实际使用的 Python 环境安装依赖。仓库开发环境可运行：

```powershell
.venv\Scripts\python.exe -m pip install "python-pptx>=1.0.2,<2" "lxml>=6,<7" "XlsxWriter>=3.2,<4"
```

将本目录放到目标配置的 `plugins/forx-ppt/`。位置应由该后端的 `hermes_constants.get_hermes_home()` 获取；不要把配置 A 的插件或项目复制到配置 B 的数据目录。仓库中的插件目录可由开发版后端直接发现。

使用宿主原有命令启用后端插件：

```text
hermes plugins enable forx-ppt
hermes ppt doctor
```

桌面端在 **能力 → 插件** 中启用 **PPT 创作台**。统一安装包内的 `desktop/plugin.js` 由宿主同步到桌面插件目录；首次安装后需要重新启动后端，再在桌面重新扫描 / 加载插件。菜单标签因 ForX 版本和语言设置可能略有不同。

如使用 ZIP 发布包，将其中的 `forx-ppt/` 解压到目标配置的 `plugins/` 下，再按上述步骤启用。远程连接需要分别确保客户端具有桌面入口、服务端具有后端插件及依赖。

## 使用

1. 侧边栏打开 **PPT 创作台**。在对话框描述主题、受众和总页数，点击“生成初稿”；也可以“空白新建”。
2. 点击页面对象，或在元素列表查找编号。可按住 Ctrl / Command 多选，并在对话中继续修改。
3. 示例指令：“把选中的标题改为‘市场机会’，字号设为 32 磅”；“母版标题统一为 34 磅”；“把 M001 的 E0001 改为公司名称”；“换成深色科技风，保留内容和局部定制”。
4. 母版源对象会标注影响全篇。页面标题的文字仍各页独立，字号等属性逐项继承；指定本页样式会形成局部覆盖。
5. 使用工具栏撤销、重做和导出；历史记录可恢复旧版本。项目关闭后保留在当前配置中，重新打开即可继续编辑。

对话使用 ForX 已配置的模型与凭据，不需要额外插件 API Key。模型不可用时，仍可使用手动文字 / 母版控件、主题切换、页面操作和导出。

## CLI 示例

初稿 JSON：

```json
{"name":"产品介绍","theme":"business","slides":[{"title":"产品介绍","layout_id":"L001","bullets":["面向企业客户"]},{"title":"主要能力","bullets":["能力一","能力二"]}]}
```

```text
hermes ppt create --input draft.json
hermes ppt show --project 返回的文稿ID
hermes ppt edit --project 文稿ID --revision 当前版本 --input operations.json
hermes ppt export --project 文稿ID --output result.pptx
```

`operations.json` 示例（编号以 `show` 实际返回为准）：

```json
[
  {"action":"update_element","target":"E0003","changes":{"text":"新的主标题"}},
  {"action":"master_style","target":"title","changes":{"font_size":34}},
  {"action":"theme","changes":{"preset":"technology"}}
]
```

支持的操作及参数定义位于 `operations.py`；模型负责提出操作，执行器会校验身份、归属、版本与数据结构，一组操作整体成功或整体保留原稿。

## 文件与兼容边界

- 生成文件为真实 PPTX：文本、形状、图片、表格和基础图表分别保留为原生对象；图表数据保存在嵌入工作簿中。
- 预览使用同一结构化文稿生成 SVG，并不是 PowerPoint/WPS 的原生渲染截图。文字排版、字体、表格和图表外观可能存在差异；溢出提示为估算，外部软件中仍需检查最终版式。
- 已验证用 `python-pptx` 重新打开、图表工作簿、原生母版 / 占位符和元数据回读。当前开发环境未发现 PowerPoint/WPS，尚未完成真实 Office 软件的视觉及保存兼容验证。
- 首版支持不超过 30 页、每页 60 个可寻址对象；单张上传图片不超过 10 MB，文稿引用的图片合计不超过 50 MB。
- `.forxppt` 包含当前结构和素材，导入创建独立文稿；当前配置的数据库保留完整版本与修改记录。跨机器导入项目不会迁移原数据库中的完整历史。
- 自身原样导出的 PPTX 可恢复身份；外部软件保存或改写后会拒绝元数据回导，避免静默丢掉外部修改。任意历史 PPTX / POTX 导入尚未实现。
- 直接继承的母版公共对象不能无提示变成某一页的独立对象；完整的单页母版变体属于后续版本。
- 当前支持受控文字格式和基础几何形状；复杂动画、SmartArt、OLE、多母版、外部 Office 实时双向同步、自动图像生成与多人协作不在此版本中。
- 页面占位符加入原生组合时会成为普通对象，保留当时的样式并显示为局部样式；需要继续继承母版的标题应保留为页面占位符。
- 需求文档的性能数值仍是目标，当前版本未完成对应的容量性能认证。
